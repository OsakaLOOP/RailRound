## 本版目标

v0.51 的核心目标不是新增大功能，而是补强“版本内容发布链路”的稳定性，避免后续出现版本更新后内容不一致、文档不可访问的问题。

本次交付覆盖三个方面：

1. `changelog` 与版本详情页映射同步。
2. 新增可直接复用的外站接入文档（npm / CDN）。
3. 让 blog 详情路由支持 docs 分类，不再只覆盖 dev。

## 本次完成内容

### 1) 版本日志与详情页映射

- 新增 `public/changelog.json` 的 `v0.51` 条目。
- 新增 `blog/src/content/blog/zh-cn/v0.51.mdx` 详情页。
- `version` 字段与文件名版本保持一致，满足构建时版本内容一致性校验。

### 2) docs 分类内容落地

新增一篇 docs 分类文章，内容是外站接入 `@railloop/route-slice-preview` 的完整说明，覆盖：

- npm 安装接入。
- CDN 直连接入。
- 样式引入方式。
- 基础渲染示例与数据结构说明。

该文章可作为后续对外引用的标准接入文档。

### 3) blog 分类路由补齐

此前详情页路由仅覆盖 `dev` 分类。若文章分类是 `docs/release/guide`，列表页会生成链接，但详情页可能 404。

本版补齐 `docs` 分类详情路由，保证 docs 文章可正常访问。

## 验收关注点

- `npm run check:release-content` 通过。
- 版本页可通过 `v0.51` 访问。
- docs 文章可通过 `docs` 分类路径访问。

## 后续建议

后续可进一步将详情页路由抽象为统一分类动态路由（一次覆盖 `dev/docs/guide/release`），减少重复维护成本。
