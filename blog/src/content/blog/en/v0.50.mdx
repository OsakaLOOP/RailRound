## 🚀 Core Architecture Upgrade

In this version, RailRound has completely transformed its original heavy SPA (Single Page Application) single-point routing model, introducing a **dual-track architecture** to perfectly solve the disadvantage of search engines being unable to crawl page content.

1. **SPA State Cascade Decoupling**: The global `activeTab` now spontaneously listens to the Address Bar (URL) for linkage, truly decoupling the forward/back/external link jump logic.
2. **Zero-Reload WebGL**: For the map area (Leaflet) that consumes the most performance and state synchronization, we ensure that the map instance is never destroyed through intelligent CSS hierarchy and visibility control, no matter how the routing page is switched.
3. **Introduction of Static Blog Layer (Astro)**: We introduced the industry's most advanced Astro pure static engine and bridged it under the `/blog/` route.
