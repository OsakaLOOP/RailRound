## 🚀 コアアーキテクチャのアップグレード

このバージョンでは、RailRoundは従来の重いSPA（シングルページアプリケーション）単一ポイントルーティングモデルを完全に変え、検索エンジンがページコンテンツをクロールできないという欠点を完璧に解決するために、**デュアルトラックアーキテクチャ体系**を導入しました。

1. **SPA状態のデカップリング**: グローバルな `activeTab` は、アドレスバー（URL）を自発的にリッスンして連動するようになり、進む/戻る/外部リンクのジャンプロジックのデカップリングを真に実現しました。
2. **WebGLゼロリロード**: 最もパフォーマンスと状態同期を必要とするマップエリア（Leaflet）については、インテリジェントなCSS階層と表示制御により、ルーティングページがどのように切り替わってもマップインスタンスが破棄されないようにしました。
3. **静的ブログ層 (Astro) の導入**: 業界最先端のAstro純静的エンジンを導入し、`/blog/` ルートの下にブリッジしました。

## 🚀 JSXコンポーネントの埋め込みデモ

デュアルトラック融合の利点を活かし、Reactと内部アルゴリズムモジュールに基づいた独立したコンポーネントをMarkdown（MDX）ドキュメントに直接埋め込むことができるようになりました！

import { RouteSlicePreview } from './../../../components/mdx/RouteSlicePreview';

export const tokyoShinagawaManual = [
  {
    lineKey: "東日本旅客鉄道:東海道線 (JR東日本)",
    fromStation: "東京",
    toStation: "品川",
  },
];

<RouteSlicePreview
  client:only="react"
  lineKey="東日本旅客鉄道:東海道線 (JR東日本)"
  startStation="東京"
  endStation="品川"
  manualSegments={tokyoShinagawaManual}
  mode="manual"
  enableModeSwitch={true}
/>
