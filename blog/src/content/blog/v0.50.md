## 🚀 核心架构升级

在这一版本中，RailRound 彻底改变了原有的重度 SPA (Single Page Application) 单点路由模式，引入了 **双轨架构体系**，以完美解决搜索引擎无法抓取页面内容的劣势。

1. **SPA 状态级联解耦**: 全局 `activeTab` 现在将自发侦听 Address Bar（URL）进行联动，真正实现前进/后退/外链跳转逻辑的解耦。
2. **WebGL 零重载**: 对于最吃性能与状态同步的地图区（Leaflet），我们通过智能 CSS 层级与显隐控制，保证无论如何切换路由页面，地图实例绝不销毁。
3. **引入静态博客层 (Astro)**: 我们引入了业界最前沿的 Astro 纯静态引擎并将其桥接在 `/blog/` 路由下。它将承担：
   - 更新日志展示（彻底释放 SPA 中冗长且影响 Bundle Size 的描述内容）
   - 技术文档指引
   - API 文档管理
