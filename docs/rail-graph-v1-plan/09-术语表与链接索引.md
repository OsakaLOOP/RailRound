# 术语表与链接索引

## 1. 使用规则
- 每个核心概念固定一个术语 ID（`RGV1-*`），后续文档修改优先保留 ID 不变。
- 跨文档引用优先使用普通 Markdown 链接，保证在 Git 环境可直接跳转。
- 开发期检索建议：`rg RGV1-` 或 `rg <术语 ID>`。

## 2026-05-24 MVP Local Pipeline Term

`RGV1-MVP-LOCAL-PIPELINE` means the Vite-dev-only Rail Graph MVP workspace
pipeline. It covers local data preparation, cleaning, source loading, topology
compile, Senseki validation, and export:

`prepare -> clean -> annotate -> compile -> validate -> export`

Its current stages are `diagnose`, `extract`, `emitFast`, `postFix`, `match`,
`manifest`, `planBatches`, and `mergeOverride`.

This term points to `docs/rail-graph-v1-mvp/00-mvp-design.md`,
`src/rail-graph-v1-mvp/pipeline.ts`, and `scripts/rail-graph-mvp-server.js`.
It is a dev/admin adapter term, not the final runtime pipeline term. When this
pipeline changes, update the MVP docs plus `03`, `04`, `05`, and this glossary.
